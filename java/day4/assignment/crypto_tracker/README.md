# 🪙 Crypto Tracker 사용 설명서

Binance의 실시간 시세 API로 **USDT 마켓 암호화폐의 가격 변동을 1초마다 추적**하는 웹 페이지입니다.
HTML · CSS · JavaScript만으로 만들었으며, 별도 설치나 라이브러리가 필요 없습니다.

## 2. 화면 구성

```
┌──────────────────────────────────────────────────────────────────┐
│ ① 🪙 Crypto Tracker                    ② ● 실시간 · 오후 9:14:01 업데이트 │
├──────────────────────────────────────────────────────────────────┤
│ ③ [ 전체 708 ] [ ★ 관심 2 ]                    ④ 🔍 [ 코인 검색 ]     │
├──────────────────────────────────────────────────────────────────┤
│ ⑤  이름      현재가(USDT)  24h 변동   24h 최고가  24h 최저가  거래대금 ▼ │
│ ⑥ ★ BTC/USDT  80,444.31   ▼ -0.34%  81,033.69  79,220.74  778.49M  │
│    ☆ ETH/USDT🔔 2,333.39   ▼ -1.48%   2,373.18   2,282.46  481.61M  │
│    …                                                             │
│ ⑦                       더보기 (100 / 708)                         │
└──────────────────────────────────────────────────────────────────┘
```

| 번호 | 이름 | 설명 |
|---|---|---|
| ① | 제목 | |
| ② | 업데이트 상태 | 초록 점 = 정상 수신 중, 빨간 점 = 연결 끊김 |
| ③ | 탭 | 전체 / 관심 항목 전환, 옆 숫자는 코인 개수 |
| ④ | 검색창 | 코인 이름으로 검색 |
| ⑤ | 열 제목 | 클릭하면 해당 열 기준으로 정렬 |
| ⑥ | 코인 행 | ☆/★ 관심 표시, 🔔 목표가 알림 설정됨 |
| ⑦ | 더보기 | 다음 100개 더 보기 |

**각 열의 의미**

| 열 | 의미 |
|---|---|
| 이름 | 코인 이름 (예: `BTC/USDT` = 비트코인을 USDT로 거래하는 마켓) |
| 현재가 | 가장 최근 거래 가격 (USDT) |
| 24h 변동 | 24시간 전 대비 등락률. ▲ 초록 = 상승, ▼ 빨강 = 하락 |
| 24h 최고가 / 최저가 | 최근 24시간 동안의 최고 / 최저 가격 |
| 거래대금 | 최근 24시간 거래된 금액 합계 (USDT). K = 천, M = 백만, B = 십억 |

> 💡 USDT는 미국 달러와 가치가 1:1로 연동되도록 만든 코인(스테이블코인)입니다. 가격을 달러로 보면 됩니다.

## 3. 기능별 사용법

### 3-1. 실시간 가격 추적

- 페이지를 열면 자동으로 **1초마다** 최신 시세를 받아옵니다.
- **USDT 마켓만** 표시하며, 거래가 중지된 코인(거래대금 0)은 제외합니다.
- 가격이 바뀌면 현재가 칸이 잠깐 **깜빡입니다.**
  - 🟩 초록 = 직전보다 상승
  - 🟥 빨강 = 직전보다 하락

### 3-2. 업데이트 상태 확인

| 표시 | 의미 |
|---|---|
| ⚪ 불러오는 중... | 첫 데이터를 받는 중 |
| 🟢 실시간 · 오후 9:14:01 업데이트 | 정상. 마지막으로 받은 시각 |
| 🔴 연결 끊김 · 3초 후 재시도 | 인터넷 끊김 또는 API 오류. 3초마다 자동 재시도, 연결되면 자동 복구 |

연결이 끊겨도 마지막으로 받은 가격은 화면에 그대로 남아 있습니다.

### 3-3. 검색

1. 검색창에 코인 이름을 입력합니다. (예: `btc`, `eth`, `sol`)
2. 입력하는 즉시 목록이 걸러지고, 이름에서 **검색어 부분이 노란색으로 강조**됩니다.

- 대소문자를 구분하지 않습니다. (`btc` = `BTC`)
- 이름 일부만 입력해도 됩니다. `bt` → BTC, WBTC, BTTC …
- `USDT`는 빼고 코인 이름만 입력하세요. (`btcusdt` ❌ → `btc` ⭕)
- 검색창 오른쪽 ✕ 버튼이나 내용을 지우면 전체 목록으로 돌아갑니다.
- **관심 탭에서 검색하면 관심 항목 안에서만** 찾습니다.

### 3-4. 관심 항목 (★)

**추가 / 해제**
- 목록에서 코인 왼쪽의 **☆를 클릭** → ★(노란색)로 바뀌며 관심 항목에 추가
- 다시 **★를 클릭**하면 해제
- 상세 창(3-7) 오른쪽 위의 ☆/★로도 추가 / 해제할 수 있습니다.

**보기**
- 위쪽 **[★ 관심]** 탭을 누르면 관심 항목만 표시됩니다.
- 관심 항목은 브라우저에 저장되어 **새로고침하거나 브라우저를 껐다 켜도 유지**됩니다. (→ [4장](#4-저장되는-데이터-localstorage))

### 3-5. 정렬

열 제목(이름, 현재가, 24h 변동, 24h 최고가, 24h 최저가, 거래대금)을 클릭합니다.

| 동작 | 결과 |
|---|---|
| 처음 클릭 | 숫자 열은 **큰 값부터**(▼), 이름은 **A→Z**(▲) |
| 같은 열 다시 클릭 | 방향이 반대로 바뀜 |
| 기본값 | 거래대금 큰 순 (▼) |

정렬 중인 열 제목 옆에 ▲(오름차순) / ▼(내림차순)가 표시됩니다.

**활용 예**
- 오늘 가장 많이 오른 코인 → **24h 변동** 클릭 (▼)
- 가장 많이 떨어진 코인 → **24h 변동** 한 번 더 클릭 (▲)

> 💡 가격이 1초마다 바뀌므로, 등락률·가격 순으로 정렬해 두면 순위가 실시간으로 바뀌면서 행 순서도 움직일 수 있습니다.

### 3-6. 더보기

- 처음에는 정렬 기준 **상위 100개**만 보여줍니다.
- 목록 맨 아래 **[더보기 (100 / 708)]** 를 누르면 100개씩 더 표시됩니다.
- 탭·검색어·정렬을 바꾸면 다시 100개부터 보여줍니다.

### 3-7. 상세 정보 창

목록에서 **코인 행을 클릭**하면 상세 창이 열립니다. (☆ 버튼을 누를 때는 열리지 않음)

| 항목 | 의미 |
|---|---|
| 현재가 | 큰 글씨로 표시, 1초마다 갱신 |
| 변동 금액 (등락률) | 24시간 전 대비 오르내린 금액과 비율 |
| 24h 고가 / 저가 | 최근 24시간 최고 / 최저 가격 |
| 시가 (24h 전) | 24시간 전 가격 |
| 거래 횟수 | 최근 24시간 체결된 거래 수 |
| 거래량 | 최근 24시간 거래된 코인 개수 |
| 거래대금 (USDT) | 최근 24시간 거래된 금액 합계 |

**닫기:** 오른쪽 위 **✕** / 창 바깥 어두운 영역 클릭 / **Esc** 키

### 3-8. 목표가 알림 🔔

원하는 가격에 도달하면 알림 창으로 알려줍니다.

**설정**
1. 코인 행을 클릭해 상세 창을 엽니다.
2. 아래 **🔔 목표가 알림** 칸에 가격(USDT)을 입력하고 **[설정]** 을 누릅니다.
3. 목록의 코인 이름 옆에 🔔가 표시됩니다.

**알림 조건은 자동으로 정해집니다.**

| 입력한 목표가 | 조건 | 예 (현재가 100일 때) |
|---|---|---|
| 현재가 **이상** | 가격이 목표가 **이상이 되면** 알림 | 120 입력 → 120 이상이 되면 |
| 현재가 **미만** | 가격이 목표가 **이하가 되면** 알림 | 80 입력 → 80 이하가 되면 |

**도달하면**
- `🔔 목표가 도달!` 알림 창이 뜹니다.
- 한 번 알린 알림은 **자동으로 해제**됩니다. (🔔 표시도 사라짐)
- 여러 코인이 동시에 도달하면 한 창에 모아서 보여줍니다.

**해제:** 상세 창의 **[알림 해제]** 버튼

- 코인마다 알림은 **1개**씩 설정할 수 있습니다. 다시 설정하면 기존 값을 덮어씁니다.
- 알림 설정도 브라우저에 저장되어 새로고침 후에도 유지됩니다.
- 알림은 **페이지가 열려 있을 때만** 동작합니다.

## 4. 저장되는 데이터 (localStorage)

| Key | 내용 | 예시 Value |
|---|---|---|
| `favorites` | 관심 항목 목록 | `["BTCUSDT","NEOUSDT"]` |
| `crypto-alerts` | 목표가 알림 | `{"ETHUSDT":{"target":1166.95,"direction":"below"}}` |

`direction`은 `"above"`(이상) 또는 `"below"`(이하)입니다.

**저장된 값 확인 / 삭제**
1. 개발자 도구 열기: `F12` (Mac: `Cmd + Option + I`)
2. **Application** 탭 → Storage → **Local storage** → 지금 주소창과 같은 주소 선택
3. Key / Value 표에서 확인. 항목을 우클릭 → **Delete**로 삭제
4. 값이 바로 안 바뀌어 보이면 🔄 버튼으로 새로고침

> ⚠️ localStorage는 **주소(프로토콜 + 도메인 + 포트)마다 따로** 저장됩니다.
> `localhost:63342`(WebStorm)에서 추가한 관심 항목은 `localhost:8000`(파이썬 서버)에서는 보이지 않습니다.

## 6. 주의 사항

- **투자 판단용이 아닙니다.** 학습용 프로젝트이며, 표시되는 시세는 지연되거나 실제와 다를 수 있습니다.
- **같은 페이지를 여러 탭으로 열지 마세요.** Binance API는 1분당 요청 한도가 있습니다. 1초마다 요청하면 한도의 약 80%를 쓰기 때문에, 탭을 2개 이상 열면 한도를 넘어 일시적으로 차단(429 오류)될 수 있습니다.
- **다른 탭을 보고 있을 때는 갱신을 쉽니다.** 사용량을 아끼기 위한 동작이며, 다시 이 탭으로 돌아오면 바로 이어서 갱신합니다.
- **데이터 사용량:** 요청 1회 응답이 약 2MB라, 오래 켜 두면 데이터를 많이 씁니다. 모바일 데이터 환경에서는 주의하세요.
- **알림 창이 떠 있는 동안에는 가격 갱신이 멈춥니다.** `alert()` 창은 브라우저의 JavaScript 실행을 잠시 멈추기 때문입니다. [확인]을 누르면 다시 갱신됩니다.

## 7. 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| 계속 "불러오는 중..." | 인터넷 연결 확인. 개발자 도구 **Console** 탭에 오류가 있는지 확인 |
| 🔴 연결 끊김이 계속됨 | 인터넷 끊김, API 요청 한도 초과(탭 여러 개), 또는 네트워크(회사·학교 방화벽)에서 Binance 접속 차단. 탭을 하나만 남기고 1~2분 뒤 새로고침 |
| ★가 새로고침하면 사라짐 | 시크릿(비공개) 창은 창을 닫으면 저장소가 지워짐. 또는 다른 주소(포트)로 열었는지 확인 (→ 4장) |
| Application 탭에 `favorites`가 없음 | ★를 한 번 이상 눌렀는지, 지금 주소와 같은 주소를 선택했는지 확인 후 🔄 |
| 검색 결과가 없음 | `USDT`를 빼고 코인 이름만 입력. 관심 탭에서는 관심 항목 안에서만 검색됨 |
| 목표가 알림이 안 뜸 | 페이지가 열려 있어야 동작. 다른 탭을 보고 있으면 갱신이 쉬므로 돌아왔을 때 확인됨 |
| 코인이 목록에서 사라짐 | 해당 코인의 거래가 중지되어 거래대금이 0이 되면 목록에서 빠짐 |

## 8. 파일 구조와 동작 원리

```
crypto_tracker/
├── index.html    화면 구조 (헤더, 탭, 검색창, 목록, 상세 창)
├── style.css     다크 테마, Grid 목록, 깜빡임 효과, 반응형
├── app.js        데이터 요청·가공·화면 갱신·저장
└── README.md     사용 설명서 (이 문서)
```

**동작 흐름**

```
   1초마다 (응답 처리가 끝난 뒤 다음 요청)
        │
        ▼
 fetch(Binance API) ──▶ 약 3,700개 코인 ──▶ USDT 마켓 + 거래대금 > 0 만 선택
                                                   │
             ┌───────────── 상태 ─────────────┐     │
             │ coins      시세 데이터          │ ◀───┘
             │ favorites  관심 항목  ◀────────┼──── localStorage "favorites"
             │ alerts     목표가 알림 ◀───────┼──── localStorage "crypto-alerts"
             │ 탭 · 검색어 · 정렬 · 표시 개수    │
             └───────────────┬───────────────┘
                             ▼
               탭 → 검색 → 정렬 → 상위 N개
                             ▼
                 화면 갱신 (값이 바뀐 칸만)
                             ▼
                 목표가 도달 확인 → 알림 창
```

**사용 API**

| 항목 | 값 |
|---|---|
| 주소 | `https://api4.binance.com/api/v3/ticker/24hr` |
| 방식 | GET, 1초 간격 (실패 시 3초 간격 재시도) |
| 사용 필드 | `symbol`, `lastPrice`, `priceChange`, `priceChangePercent`, `highPrice`, `lowPrice`, `openPrice`, `volume`, `quoteVolume`, `count` |

| 상수 | 기본값 | 의미 |

| `FAVORITES_KEY` | `"favorites"` | 관심 항목 저장 key |
| `ALERTS_KEY` | `"crypto-alerts"` | 목표가 알림 저장 key |
