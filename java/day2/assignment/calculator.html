콘솔창 계산기 프로그램

다음의 세가지 조건을 갖춘 사칙연산 계산기 입니다.

  1. 4칙연산에 대한 계산이 가능할 것.
  2. 길이가 긴 계산식도 계산이 가능할 것.
  3. 사칙연산 우선순위( * , / 가 +, - 보다 먼저 계산됨)가 적용될 것.

[ 사용법 ]

Windows OS의 경우

1. F12 키를 눌러 콘솔 창을 여세요.

2. start()를 콘솔창에 입력하여 계산기를 실행합니다.

Mac OS의 경우

1. Option + Command + i 키를 눌러 콘솔 창을 여세요.

2. start()를 콘솔창에 입력하여 계산기를 실행합니다.
